# postcard-word-prediction

Word Prediction на материале почтовых открыток

Проект в рамках курсов «Интеллектуальный анализ данных и основы машинного обучения» и «Автоматическая обработка естественного языка».  
Задача — предсказание пропущенных слов (помеченных [нрзб]) в текстах корпуса «Пишу тебе».

Над проектом работали: Крамкова Мария, Мокина Марина, Хамидуллин Дамир.
